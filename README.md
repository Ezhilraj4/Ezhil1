# Ezhil — Smooth Scroll Portfolio

## Run locally
1. Extract the ZIP file.
2. Open the `ezhil_smooth_portfolio` folder.
3. Double-click `index.html`, or open the folder in VS Code and use the Live Server extension.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling, smooth scrolling and CSS animations
- `script.js` — scroll progress, active navigation, reveal-on-scroll and mobile menu

## Personalise
- Edit the About, interests, project and journey text in `index.html`.
- Replace the portfolio URL in the contact section if needed.
- Update colours in the `:root` variables at the top of `style.css`.

The page uses Google Fonts when online and includes a reduced-motion accessibility fallback.
